# NAS-Tools Web 全页面设计提示词

本文件由当前路由、Jinja 模板、Lit 组件与 `awesome-gpt-image-2` 本地案例共同提炼。页面范围见 [页面清单](page-inventory.md)，精确视觉规则见 [设计规范](design-system.md)。共 35 个页面画板、8 个通用列表变体、42 个弹层/抽屉/菜单规格及 10 个跨页面状态增量。这里描述设计要求，不代表所有设计图片均已生成或所有交互已完成验证。

## 复制与生成方式

每次发送给图像 AI 的完整输入为：**公共前缀 + 一个 P 页面块（或一个 D 弹层块）+ 按需选择的 V 变体 / S 状态块**。不要只发送编号；复制对应代码块全文。每次请求携带同一已生成参考图；品牌与设计 token 不随页面改变。AI 若支持文件上下文，也可直接提供本文件和设计规范，明确要求按编号依次逐张生成。

为了清楚阅读每个页面，不要一次把 35 页挤在一张图里。先生成设计系统板，再逐页输出桌面图；长表单可以分连续上下两幅，名称中标明 `part-1`/`part-2`。每一页都需要单独画板，复用模板的不同路由仍保留各自标题和字段。

```text

统一风格：暖白画布、白色内容卡片、深森林侧栏，媒体页使用海报表达内容，管理页使用清晰表格、紧凑任务行和分区表单。

颜色严格锁定：canvas #F5F6F2，surface #FFFFFF，sidebar #142923，
text #20332D，muted #68786F，primary #187761，soft #E7F2EB，
border #DEE5DD，warning #B77920，danger #BD4C42。
深色变体只在明确要求时使用：canvas #101B17，surface #192923，
text #E7EEE9，muted #A5B6AC，primary #65C8A8，导航仍为深森林。
深色主按钮用薄荷底配深色文字，不照搬浅色的白字。

字体为 Inter / 系统西文字体 + PingFang SC / Noto Sans SC 中文。
页面标题 28/36 px，分区标题和管理卡片标题18/26 px，正文14/22 px，
辅助文字12/18 px；关键数值使用等宽数字。
间距只用4/8/12/16/24/32 px；卡片圆角12 px，控件圆角8 px；
细边框，轻阴影；不使用夸张霓虹和大面积玻璃效果。
桌面侧栏232 px、顶栏72 px、内容边距32 px，表单短字段两列，
长路径/地址/说明跨行；主要控件40 px，触屏命中区域至少44 px。
海报2:3，人物头像1:1，媒体标题与年份/评分常显。

基础画布为1440×1000的正面平面Web截图；完整长页可1440×1800或更长，
若工具尺寸有限则分连续上下画板，不能把全文压成微小字。
每次只生成选定的一页或一个状态；不绘制设备、浏览器框、透视样机、水印、
Figma面板或与产品无关的演示展板。全页面组合图只能作为补充总览。
所有字段和按钮必须使用页面增量指定的准确中文，必要的英文术语原样保留。
优先保证标签与操作清楚；无法可靠显示长样例时缩短样例，不能改变真实字段名。

所有截图中的站点、电影、用户、路径和数值都是设计样例，不能伪装成实测数据。
站点用“站点 A/B”，域名使用 example.com，密码、Cookie、API Key、Passkey遮蔽；
媒体可用“远山来信”“海岸之间”等虚构作品和原创海报。
不添加本项目没有的订阅、播放、媒体整理、Emby/Jellyfin、付费、云同步、
插件市场、企业微信、聊天助手或虚假数据指标。
下载器只使用 qBittorrent/Transmission；通知类型以当前 Telegram 为限。

保留真实业务能力：探索、资源搜索、站点管理、下载管理、服务、系统设置。
仅支持一个管理员登录，登录后显示全部功能。服务端未提供的数据不可补造。
主操作明确，危险动作语义明确，表单标签常显，交互不只依赖颜色或hover。
默认视图含真实可用的主要内容，另按状态增量生成加载、空、错误和响应式画板。
全套页面严格沿用同一设计系统和上传的参考图；保持外壳、字号、颜色、间距和组件一致。
```

## 与原项目边界一致

- `/search` 是种子资源聚合结果；`/recommend?type=SEARCH` 是媒体元数据列表，二者不可合并丢失内容。
- `/downloader` 为全局下载器设置；`/userdownloader` 为刷流使用的自定义下载器，数据来源不同。
- `/service` 与 `/service_setting` 分别为工具操作和配置页；`/tools` 当前只有签到工具。
- 所有业务页仅供管理员登录后使用，导航分组用于组织功能。
- Swagger 使用独立生成页面，主应用外壳样式不等于已经覆盖其 DOM。
- 图片里的真实小字若受图像模型能力限制，代码实现仍以本文件字段与实际源码为准。
