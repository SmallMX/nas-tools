# NAS-Tools Web 设计规范

本规范同时约束 AI 设计图、Web 实现和后续新增页面。页面功能以当前路由、模板、组件和登录认证为准，完整清单见 [页面清单](page-inventory.md)，生成提示词见 [全页面提示词](page-prompts.md)。图中虚构媒体、站点、任务名称及数值只用于展示布局，不代表连接状态或业务实测结果。

## 设计方向

使用暖白画布、白色内容卡片、深森林绿色侧栏和克制的薄荷色强调。媒体发现页以海报、清楚的片名和元数据建立浏览体验；管理页以紧凑任务行、表格和分区表单承载信息。标题和主要操作始终可见，海报上的悬停层只能补充信息。

通过边框、间距和文字层级区分内容，减少阴影和大面积渐变。登录页可以使用原创抽象媒体图形，媒体详情可以使用有渐变遮罩的背景海报；设置、站点、任务页面不放装饰性主视觉。所有可点击入口应能对应到真实操作或路由。

## 颜色

| 语义 | 浅色模式 | 深色模式 | 用途 |
|---|---|---|---|
| 画布 | `#F5F6F2` | `#101B17` | 主页面背景 |
| 表面 | `#FFFFFF` | `#192923` | 卡片、表单、弹窗 |
| 侧栏 | `#142923` | `#142923` | 导航外壳 |
| 正文 | `#20332D` | `#E7EEE9` | 标题、正文、主要数值 |
| 次级文字 | `#607166` | `#A5B6AC` | 说明、元数据、时间 |
| 主色 | `#187761` | `#65C8A8` | 主操作、链接、焦点、选中状态 |
| 浅强调 | `#E7F2EB` | `#244638` | 选中底色、轻提示、状态标签 |
| 边框 | `#DEE5DD` | `#33493D` | 分隔线、输入框、卡片 |
| 警告 | `#B77920` | `#E5B362` | 需要注意、暂停、缺失配置 |
| 错误 | `#BD4C42` | `#F08B80` | 操作失败、危险操作 |

深色主按钮使用薄荷底、深森林色文字；浅色主按钮使用主色底、白字。不要把浅色模式颜色机械反转。成功使用主色体系；中性、加载、未执行使用次级文字和细边框。错误、警告均附明确状态文字或图标，不仅依靠颜色。灰色文字不能为了柔和而降低到难以阅读。

普通输入框与选择框在深色模式显式沿用表面、正文和边框 token，避免旧框架的蓝色表面覆盖。占位文字使用辅助文字色且不再额外降低不透明度。浅色辅助文字与画布的颜色值对比约为 `4.78:1`，不表示所有内容和状态已完成对比度审计。

## 字体与排版

西文依次使用 `Inter`、系统无衬线字体；中文依次使用 `PingFang SC`、`Noto Sans SC`、系统无衬线字体。可用时复用本地字体，不把外网字体请求作为页面可用的前提。

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| 页面标题 | 28 / 36 px | 600–700 | 页面唯一主标题 |
| 分区标题 | 18 / 26 px | 600 | 卡片组、配置分区 |
| 管理卡片标题 | 18 / 26 px | 600 | 站点、任务、工具名称 |
| 正文与控件 | 14 / 22 px | 400–500 | 正文、标签、按钮、表格 |
| 辅助信息 | 12 / 18 px | 400–500 | 时间、来源、单位、说明 |
| 关键统计 | 28 / 36 px | 600 | 少量需要快速识别的指标 |

数据使用等宽数字 `font-variant-numeric: tabular-nums`。路径、资源文件名、日志和结构化数据可用系统等宽字体。文件名、URL 和路径允许在合适位置换行；表格中的长标题提供可访问的完整文本入口。媒体片名最多两行，年份和评分占独立元数据行，不能依靠 hover 才能看到。

## 尺寸、间距与布局

- 间距只使用 `4 / 8 / 12 / 16 / 24 / 32 px`；密集数据的内部微调应有明确理由。
- 侧栏宽度 `232 px`，顶部栏高度 `72 px`，桌面主内容外边距 `32 px`。
- 卡片圆角 `12 px`，按钮、输入框、下拉框和弹出菜单圆角 `8 px`；徽标可用胶囊圆角。
- 卡片默认内边距 `24 px`，密集任务行或表格工具条 `16 px`，相邻分区间距 `24–32 px`。
- 表单默认两列，字段间距 `16–24 px`；长地址、路径、令牌、说明、代码编辑区域跨整行。有限宽度设置页可用单列而不把短字段无限拉宽。
- 普通输入控件最小高度 `40 px`；桌面普通按钮最小 `38 px`、小按钮 `32 px`。手机普通按钮、小按钮和菜单项最小高度 `44 px`，输入框与选择框文字 `16 px`；触屏交互仍需核对至少 `44 × 44 px` 的完整命中区域。
- 表格常规行高约 `52–64 px`，含第二行说明时可增高；所有数字列右对齐，标题列左对齐，批量勾选列固定窄宽。
- 海报固定 `2:3` 比例，头像固定 `1:1`；同一列表尺寸一致，图片加载前保留占位面积。

页面外壳只渲染一次。业务页采用统一的标题、说明、操作区和内容容器，不在局部模板再嵌套完整侧栏。侧栏提供“榜单推荐”和“探索”两个直接入口；TMDB、腾讯视频、爱奇艺、芒果视频、Bangumi 在探索页内切换。管理员登录后可访问全部业务功能。

导航不依赖角色或权限列表。默认页为榜单推荐，显式链接和历史页面继续优先。可运行 `scripts/verify_ui_navigation.cjs` 在隔离预览中核对完整菜单与首屏跳转。

## 共享组件契约

| 组件 | 必须支持 | 使用约定 |
|---|---|---|
| 应用外壳 | 当前导航、全局搜索、主题、管理员与消息入口 | 管理员完整导航，移动端使用抽屉 |
| 页面标题 | 标题、可选说明、主操作、次操作 | 所有尺寸保留标题，操作区允许换行 |
| 内容卡片 | 标题、工具区、正文、可选底部 | 避免卡片套卡片，相关字段按分区组织 |
| 主要 / 次要 / 危险按钮 | 正常、hover、focus、disabled、loading | 操作中保留原按钮宽度，阻止重复提交 |
| 表单字段 | 标签、必填、帮助、错误、只读 | 标签常显，错误紧邻字段，密码默认遮蔽 |
| 复选 / 单选 / 开关 | 未选、选中、禁用、焦点 | 批量选择使用复选框，开关用于明确二值状态 |
| 状态标签 | 图标、文字、语义颜色 | 使用“运行中”“已暂停”“失败”等真实状态 |
| 工具条 / 筛选条 | 关键词、筛选、重置、计数、选择反馈 | 提示筛选影响，重置后保留页面上下文 |
| 媒体卡片 | 图片、标题、年份、评分、类型、详情入口 | 标题常显，缺失图片和评分有稳定占位 |
| 任务行 | 名称、元数据、状态、进度、操作 | 进度数值与条形一起显示，暂停／继续常显，删除置于更多菜单 |
| 数据表格 | 表头、排序、选择、操作、空行、分页 | 保留原字段和数据语义，手机上允许局部横向滚动 |
| 统计卡 / 图表 | 标签、数值、单位、时间范围、图例 | 缺少数据使用“暂无数据”，不能画虚假零增长 |
| 空状态 | 图标、标题、解释、相关行动 | 未配置、暂无记录、筛选无结果分别表达 |
| 反馈条 | 成功、失败、警告、加载 | 保留接口返回的有效说明，不伪造完成状态 |
| 弹窗 / 抽屉 | 标题、关闭、正文、主次操作、滚动 | 复用统一外框、焦点与键盘行为 |
| 分页 | 当前页、前后页、边界禁用 | 不把后端估计页数包装成准确总数 |

优先使用现有 Lit 组件、Jinja 宏和共享样式实现一致性。不同技术渲染出的同一控件使用相同 token 和交互语义。可在不改变后端契约的前提下调整模板、布局和局部逻辑，业务 API、字段名、登录认证、动态 ID、回调和表单取值范围需要保留。

本轮的共享 token 位于 [design-system.css](../../web/static/css/design-system.css)，使用 `--nt-canvas`、`--nt-surface`、`--nt-text`、`--nt-muted`、`--nt-primary`、`--nt-primary-soft`、`--nt-border`、`--nt-warning`、`--nt-danger`；间距使用 `--nt-space-*`，外壳尺寸为 `--app-sidebar-width` / `--app-header-height`。深色通过 `body.theme-dark` 切换。

Jinja 页面使用 [macro/ui.html](../../web/templates/macro/ui.html) 的 `UI.page_header(title, description='', eyebrow='', title_id='', count=none, description_id='')`，操作区通过 call block 传入；分区使用 `UI.section_heading(title, description='')`，空状态可使用 `UI.empty_state(title, description='')`。保留 `title_id`、`description_id` 能让动态文字绑定继续工作，避免在新标题外再留一份隐藏旧标题。

`normal-card` 的 `card-detail-url` 可为视频平台提供 HTTP(S) 详情链接，使用新标签页并设置 `noopener noreferrer`；链接无效时不能导航到未知地址。平台列表的 `source_id` 仅用于去重，不能作为 TMDB ID。卡片继续保留独立的“搜索资源”按钮，以片名和影视类型发起检索。

探索页结构参考 MoviePilot：顶部为单排来源标签，其下为“种类”及多行筛选标签，最后是海报网格；不重复放置大标题、说明横幅或下拉式分类入口。`discovery-navigation` 统一来源切换，`discovery-filters` 每行显示常显标签和可直接点击的选项，当前选项使用 `aria-pressed` 与主题强调色。TMDB 的电影与电视剧在种类行切换，旧 URL 保持可访问并归属于同一探索导航。

视频平台通过 `get_streaming_filters` 按来源和种类加载真实筛选行，可包括排序、类型、地区、年份和资费；字段与选项以接口返回为准，不补造平台不支持的选项。初始加载保留种类和基础排序，筛选请求失败显示“重新加载筛选”。切换种类清空关联的子筛选并恢复默认排序，筛选变化从第一页加载；旧筛选或旧页面的异步响应不能覆盖当前页面。

视频平台探索页复用推荐列表的加载、空、失败与重试状态。筛选选择写入该平台自身路由的 `params`，侧栏“探索”与当前来源标签保持高亮；`has_more=false` 表示已到末页，部分条目过滤后的空页仍可继续加载。列表只显示已加载数量，不据此推算平台总量。

榜单推荐页采用“全部／电影／电视剧／动漫／榜单”分类标签与横向海报分区，保持独立的榜单推荐导航高亮，不放宣传横幅。十三个影视来源及分类见 [页面清单](page-inventory.md)。每个分区保留真实来源名称、查看全部入口和独立资源搜索；“豆瓣最新电影／剧集”表示按最新排序的发现结果，不能复用即将上映的列表。

榜单在进入视口前 `300px` 开始加载，同一页面最多同时请求三个分区；分类切换后不再请求待加载的旧分类分区。前端只复用五分钟内成功且非空的结果，空结果和失败都允许手动重试，不能以旧失败快照阻止恢复。加载失败显示来源的有效错误说明，成功空列表显示“暂无内容”；一行异常不清除其它已加载行，也不将异常伪装成空榜单。

豆瓣榜单通过官方公开 Rexxar 接口获取，不依赖 Frodo API Key／Secret；卡片详情在原接口未返回有效数据时回退到官方公开详情，搜索协议保持不变。公共接口可能发生网络或来源侧异常，预览样例及静态检查不代表生产网络下始终可用。

资源搜索标题用于进入种子详情，无有效详情链接时为普通标题；桌面和手机均保留明确“下载”按钮，有详情或种子文件链接时保留“更多”。站点、编码、体积、发布组使用中性元数据样式，促销条件使用浅强调色。下载弹层常显资源名和已有的站点／质量／体积，解释自动选择目录的规则；失败保留选择并在弹层内反馈，成功提供“查看下载任务”和“继续浏览”。

下载任务页支持名称搜索、状态筛选、结果计数和无结果重置；任务行采用 `16 px` 内边距，暂停／继续直接可见。删除成功仅移除对应任务并保留筛选；轮询失败显示更新失败提示并保留上次数据。状态来自接口提供的状态与进度，完成不等于一定正在做种。

任务复选框与“选择可见任务”建立初始批量范围，仅对当前可见的已选任务执行暂停／继续；筛选隐藏的任务会取消选择并明确提示。“清空选择”只清除选择，不改变任务状态。批量控制逐项请求既有接口，结果清单保留任务名及等待、执行中、成功、失败、未执行状态；失败项可按清单重试，不重复执行成功项。执行期间锁定冲突的单项控制、选择与筛选。“停止后续操作”让当前请求完成后停止队列，切页也不再启动剩余项，均不声称撤销已发出的请求。成功表示下载器接受指令，任务状态仍以随后刷新为准；不提供批量删除。

签到页先展示紧凑摘要与今日状态，失败和待执行置前；“执行待签与重试”为主操作，“强制全部执行”需说明范围并再次确认。低频执行策略收纳在可折叠分区，保存按钮在分区底部。签到行与站点维护互相提供定位入口，按站点 ID 优先、名称回退匹配；同名或未找到时明确说明，不自动打开编辑表单。

## 交互与状态

### 加载与错误

页面加载使用与最终布局一致的骨架或轻量加载提示。按钮请求使用局部 loading，已有数据刷新时保持可见。应用外壳初始化失败显示“界面加载失败”和“重新加载”，不能留下一块永久空白。

每个列表至少设计初次空状态、筛选无结果、加载中和加载失败。失败状态提供与当前实现对应的重试或刷新入口。外部站点失败、元数据服务失败、下载器不可达与普通空列表要区分。服务端未提供细分状态时，保留其实际错误说明，不推断原因。

### 表单与敏感内容

字段标签、帮助文字、占位文字承担不同职责。错误保留用户已填写内容。已有凭据保持脱敏或留空的现有语义；设计图一律使用遮蔽值，不能展示真实 Cookie、密码、Passkey、API Key 或访问地址。保存成功、连接测试成功、运行完成是不同结果，不可混用。

长表单按实际保存作用域注册 `NasToolsUI.trackForm`，基础、媒体、服务、安全、实验室、CookieCloud、下载器连接、目录和签到执行策略分别跟踪，不把搜索输入当作配置草稿。保存按钮写明分区，底部 `role="status"` 区分未修改、有未保存更改、保存中、已保存与失败。提交时捕获快照，只有成功响应才确认该快照；请求期间继续输入时显示仍有未保存更改，失败不关闭表单或清空输入。下载器“测试已保存连接”只测试已保存的配置，存在草稿时先提示保存。

切换页面或浏览器历史前，有草稿时使用原生 HTML `dialog` 明确询问“放弃修改并离开”，默认聚焦“继续编辑”；取消保留当前页面与输入。关闭编辑弹窗时使用不同文案“关闭并保留本页草稿”，草稿仍会在离开页面时触发提醒；关闭不是保存。刷新或关闭浏览器由原生离开警告保护。快照与草稿只在页面内存中，不写入本地存储或历史 HTML。

### 危险操作

删除站点、任务、种子、缓存和重启等操作使用可识别的危险按钮及现有确认流程。确认内容明确当前对象与真实动作；种子任务删除是否同时删除文件必须使用现有字段语义，不能隐去差异。确认框主按钮写具体动作，避免无上下文的“确定”。

下载任务的现有后端语义为同时删除文件，因此入口和确认按钮均写“删除任务及文件”，正文包含任务名与不可撤销后果。确认前不提交请求；失败保留任务并展示实际错误，不添加尚未实现的“保留文件”选项。

### 弹层

小型反馈框建议 `440–480 px`，表单框 `640–800 px`，目录、日志、明细等密集内容可扩至 `1040 px`；所有宽度受视口减去两侧 `16 px` 约束。标题与底部操作区保持可见，长内容在正文滚动。桌面消息抽屉建议宽 `400 px`，移动端接近全屏。

弹窗有明确可访问名称，支持焦点进入、焦点约束和关闭后回到触发控件；链式反馈关闭后也尽量返回最初入口，入口已消失时聚焦主内容。编辑弹窗支持 Esc，未保存内容由共享草稿确认处理；等待与进度等不可取消操作仍按实际能力提供控制。原生未保存确认位于当前模态层中，避免两套焦点约束争夺焦点；Esc 或“继续编辑”均不授权丢弃草稿。

## 页面事件与异步请求

局部模板使用 IIFE 保存页面状态，通过 `NasToolsUI.bindActions('#page_content', handlers)` 集中绑定
`data-nt-click`、`data-nt-change` 等事件；动态数据用 `data-nt-args='{{ values|tojson }}'` 传递，
不要写内联 `on*` 或 `javascript:` 链接，也不要按属性值动态查找全局函数。复选框和单选框使用 `change`，
保留原生勾选行为；Lit 组件继续用 `@click` 等事件绑定。

页面请求使用与 `ajax_post` 参数兼容的 `NasToolsUI.pageAction`，网络请求仍由 `NasToolsApi` 发出。
切页和历史恢复会更新页面版本、清理 `pageTimeout` / `pageInterval`；旧业务请求正常完成，但不再执行旧页面的回调。
导航请求在写 DOM 前检查版本并取消被替代的片段请求，防止旧 HTML 及脚本覆盖新页面。日志、消息中心等外壳任务保留独立生命周期。

含已跟踪表单的历史项只记录路由与滚动等导航信息，不缓存表单 HTML；后退／前进重新请求服务器的已保存值，避免恢复旧属性或凭据草稿。用户取消离开时恢复历史位置并保留当前草稿；确认离开后关闭旧模态层并释放当前表单跟踪器。

表单先校验，再用 `NasToolsUI.withButton` 包裹返回 Promise 的操作；同一按钮的进行中操作不重复提交，
成功或失败后恢复捕获的原按钮。响应字段、业务提示、确认弹窗和能力条件由原页面处理，不在通用层推测。
文件树通过幂等委托绑定支持新增目录行，关闭或切页时清理临时监听器。

静态资源删除前需核对模板、JS 导入、CSS URL、manifest 和 Python 动态配置；Ace 模式／worker／主题、
PWA 图标与启动图等动态依赖不能仅凭文件名没有直接引用而删除。`tests/test_frontend_assets.py` 检查资源链与事件约定。

## 响应式

| 视口 | 外壳 | 内容 |
|---|---|---|
| ≥1200 px | 232 px 侧栏，72 px 顶栏 | 32 px 外边距；海报通常 5–6 列；任务表格完整展示 |
| 992–1199 px | 保留现有导航折叠能力 | 24 px 外边距；减少海报和统计卡列数；工具条换行 |
| 768–991 px | 侧栏转抽屉，搜索保留 | 24 px 外边距；卡片 2–3 列；设置视字段长度改单列 |
| <768 px | 可打开导航抽屉，保留页面标题和主题入口 | 16 px 外边距；海报 2 列；表单单列；探索来源及筛选选项行局部横向滚动；长表格容器内横向滚动 |

移动端不隐藏重要状态、片名、表单标签或主要操作。任务可改为两行信息：首行为名称与状态，次行为进度与操作；不能仅因窄屏丢弃暂停、继续或查看明细。图表收窄时减少刻度，保留单位和图例。弹层长表单使用正文滚动，底部按钮不可遮挡最后一个字段。

## 可访问性与动效

正文目标对比度至少 `4.5:1`，大文字和非文本可操作边界目标至少 `3:1`；这是验收要求，不代表已完成自动审计。使用语义按钮、标签、表头和可访问名称。可点击图标有文字标签或辅助名称，图像有符合用途的替代文本。

相同用途的菜单使用明确的动作名称；统计页的做种明细与活动入口包含对应站点和数值，不使用 `seeding_info`、`activity` 等内部名称作为读屏文案。

全局搜索快捷键在 Bootstrap 弹窗、抽屉或原生 `dialog` 打开时不抢占焦点。复选框、表单字段及动态结果均有相应名称或状态通知；缩放与键盘检查应覆盖新增批量操作、未保存确认及链式反馈，具体执行范围记录在交付说明中。

键盘焦点建议使用主色 `2 px` 外描边和 `2 px` 偏移。展开按钮同步 `aria-expanded`，当前导航有当前页语义，动态结果使用适当的状态通知。动效控制在 `120–180 ms`，尊重 `prefers-reduced-motion`；不以无限闪烁或强烈位移动画表达普通加载。

## 设计图与代码交接

1. 先固定本规范，再生成设计系统板；每次单页生成携带公共前缀、独立页面增量及相同参考图。
2. 媒体页、任务页、数据页、设置页分别生成高保真图，复杂表单和弹层单独出图。组合总览只用于检查连续性。
3. 设计图中的微小文字不是字段权威来源；实现按模板、接口和本页提示词确定真实字段。
4. 实现优先建立 token、外壳与共享组件，再覆盖业务模板和状态；不能只改入口页面或静态截图。
5. 验证记录必须说明真实运行方式、检查范围、失败或未检查项。设计样例、生成图片和代码静态检查不能代替真实服务集成验证。

## 后续新增页面

新增页面先补 [路由矩阵](page-inventory.md)，复用一个现有页面族，再添加独立提示词和状态说明。新 token 必须有跨页面语义，避免为单一页面新增相近颜色和随意间距。新增操作先确认后端能力和登录认证，再设计入口。项目 UI Skill 应指向本文件及提示词文档，避免复制后逐渐出现两套规范。
